# Despertador NFC

Alarma diaria para Android que **solo vibra** (sin sonido) y **solo se para acercando una tarjeta NFC** registrada en la app.

## Uso

1. Abre la app y pulsa **Registrar tarjeta**; acerca la tarjeta al teléfono.
2. Toca la hora para elegirla y activa **Alarma diaria**.
3. Cuando llegue la hora el teléfono vibra sin parar. Desbloquéalo, abre la app (o la notificación) y acerca la tarjeta.

La alarma sigue vibrando aunque cierres la app, apagues la pantalla o reinicies el teléfono.

## Instalación

Cada cambio en `main` compila la APK y la publica en **Releases**. Todas las versiones llevan la misma firma, así que se actualizan encima de la anterior.

Requiere Android 9 o superior y NFC.
