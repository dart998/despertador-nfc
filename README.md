# Despertador NFC

Alarma diaria para Android que **solo se para acercando una tarjeta NFC** registrada en la app. Se puede elegir si vibra, si suena y el mensaje que muestra.

## Uso

1. Abre la app y pulsa **Registrar tarjeta**; acerca la tarjeta al teléfono.
2. Toca la hora para elegirla y activa **Alarma diaria**.
3. Cuando llegue la hora la alarma salta y no para. Pulsa **Desbloquear**, desbloquea el teléfono y acerca la tarjeta.

La alarma sigue activa aunque cierres la app, apagues la pantalla o reinicies el teléfono.

## Instalación

Cada cambio en `main` compila la APK y la publica en **Releases**. Todas las versiones llevan la misma firma, así que se actualizan encima de la anterior.

Requiere Android 9 o superior y NFC.
